# UI Guidelines

Version: 1.0

This document defines the visual design of the application.

---

# Design Philosophy

The application should feel

- Clean
- Modern
- Professional
- Fast
- Minimal

Avoid unnecessary decorations.

Every screen should prioritize usability.

---

# Target Devices

Primary

- Android Phones
- Android Tablets

Compatible

- iPhone
- iPad

---

# Theme

Light Theme only (v1)

Dark Mode can be added later.

---

# Colors

Primary

Blue

Secondary

White

Accent

Green (Success)

Red (Delete)

Yellow (Warning)

Neutral

Light Grey backgrounds

Avoid using too many colors.

---

# Typography

Simple and readable.

Use only one font family.

Headings

Bold

Body

Regular

Buttons

Medium

Never use decorative fonts.

---

# Border Radius

Use rounded corners consistently.

Cards

12-16px

Buttons

12px

Input Fields

12px

---

# Spacing

Maintain consistent spacing.

Between sections

24px

Between fields

16px

Inside cards

16px

Never overcrowd the screen.

---

# Buttons

Primary Button

Filled

Secondary Button

Outlined

Delete

Red

Disabled

Reduced opacity

Buttons should have consistent height.

---

# Input Fields

All inputs should have

- Label
- Placeholder
- Validation message

Required fields should be clearly indicated.

---

# Forms

Large touch targets.

One field per row.

Use appropriate keyboard types.

Examples

Phone

Numeric keyboard

Email

Email keyboard

Notes

Multi-line

---

# Home Page

Contains

- Lead Form
- Review Button
- Save Button

Simple and distraction-free.

---

# CRM Page

Contains

- Search Bar
- Filters
- Lead List
- Edit
- Delete
- Export Excel

Prioritize readability.

---

# Lead Card

Each lead should display

- Name
- Phone
- Home Type
- Location
- Created Date

Actions

Edit

Delete

Cards should be easy to scan.

---

# Search

Always visible.

Instant search.

Clear button available.

---

# Filters

Open as a bottom sheet or modal.

Easy to reset.

Apply button.

---

# Empty States

If no leads exist

Display

"No leads found."

Show a button

"Add New Lead"

---

# Loading

Use simple loading indicators.

Never block the UI unnecessarily.

---

# Dialogs

Use confirmation dialogs for

- Delete

Use review dialog before

- Save

---

# Responsiveness

The application must work on

Phones

Portrait

Landscape

Tablets

Without layout issues.

Avoid fixed widths.

---

# Accessibility

Readable font sizes.

Good color contrast.

Large touch targets.

Support screen zoom.

---

# Animations

Keep animations subtle.

Use only when they improve UX.

No flashy transitions.

---

# Icons

Use a single icon library.

Icons should clearly communicate actions.

---

# AI Rules

Maintain a consistent design across all screens.

Do not redesign existing components unless requested.

Reuse existing UI components whenever possible.

Prioritize usability over visual effects.
